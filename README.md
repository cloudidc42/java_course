# หลักสูตรเขียนโปรแกรมและพัฒนาเว็บแอปพลิเคชันด้วย Java

หลักสูตรนี้พาผู้เรียนเดินทางจาก **ระดับพื้นฐานที่สุด** ไปจนถึง **ระดับมืออาชีพและระดับโลก**
โดยแบ่งเนื้อหาออกเป็น **Part** (ตอน) ตามลำดับขั้นตอนที่ 1 ถึง 1000+ ครอบคลุมตั้งแต่ไวยากรณ์
พื้นฐานของภาษา Java, การเขียนโปรแกรมเชิงวัตถุ (OOP), โครงสร้างข้อมูลและอัลกอริทึม,
Java ขั้นสูง (Concurrency, Streams, JVM Internals), การพัฒนาเว็บแอปพลิเคชันด้วย Spring Boot,
สถาปัตยกรรม Microservices, DevOps/Cloud ไปจนถึงการเตรียมตัวทำงานจริงในระดับมืออาชีพ

## วิธีใช้หลักสูตรนี้

1. เริ่มอ่านที่ [`CURRICULUM.md`](./CURRICULUM.md) เพื่อดู **แผนที่หลักสูตรทั้งหมด** (Roadmap)
   ว่ามีกี่ Part เนื้อหาแต่ละ Part ครอบคลุมอะไรบ้าง และตรงกับขั้นตอนที่เท่าไรใน 1-1000
2. เข้าไปอ่านเนื้อหาแต่ละ Part ได้ที่โฟลเดอร์ [`parts/`](./parts/) โดยไฟล์จะถูกตั้งชื่อ
   ตามรูปแบบ `part-XXX-ชื่อหัวข้อ.md` เรียงจากน้อยไปมาก
3. ทุก Part สามารถ**ใช้งานได้จริง 100%** — มีโค้ดตัวอย่างที่คอมไพล์และรันได้จริง
   คำอธิบายทีละขั้นตอน แบบฝึกหัดพร้อมเฉลย และสรุปท้ายบท
4. แนะนำให้เปิด IDE (IntelliJ IDEA / VS Code + Extension Pack for Java) ควบคู่ไปด้วย
   แล้วลงมือพิมพ์โค้ดตามจริงในทุก Part ห้าม copy-paste อย่างเดียว

## โครงสร้างหลักสูตรโดยสรุป

| ส่วน | Part | ระดับ | หัวข้อหลัก |
|---|---|---|---|
| 1 | 1-20 | พื้นฐาน (Foundations) | ไวยากรณ์ภาษา, ตัวแปร, เงื่อนไข, ลูป, Array, Method, OOP เบื้องต้น |
| 2 | 21-35 | โครงสร้างข้อมูล & อัลกอริทึม | Collections, Generics, Recursion, Sorting/Searching, Data Structures |
| 3 | 36-55 | Java ระดับกลาง-สูง | Streams, Lambda, Concurrency, Design Patterns, Testing |
| 4 | 56-70 | Java ขั้นสูง & Tooling | JDBC, Maven/Gradle, JVM Internals, Networking, JSON |
| 5 | 71-90 | Web Development | Servlet, Spring Boot, REST API, JPA/Hibernate, Security |
| 6 | 91-105 | ระดับมืออาชีพ/โลก | Microservices, Cloud, DevOps, System Design, โปรเจกต์จบหลักสูตร |

รายละเอียดทั้งหมดอยู่ใน [`CURRICULUM.md`](./CURRICULUM.md)

## สถานะความคืบหน้า

ดูสถานะว่าตอนไหนเขียนเสร็จแล้วได้ที่ [`PROGRESS.md`](./PROGRESS.md)
หลักสูตรนี้เป็นเอกสารที่ **เติบโตต่อเนื่อง (living document)** — จะมีการเพิ่ม Part ใหม่ ๆ
เข้ามาเรื่อย ๆ จนครบตามแผนที่วางไว้

## ข้อกำหนดเบื้องต้นของผู้เรียน

- ไม่จำเป็นต้องมีพื้นฐานการเขียนโปรแกรมมาก่อน (Part 1-10 ปูพื้นฐานให้ตั้งแต่ศูนย์)
- ควรมีเครื่องคอมพิวเตอร์ที่ติดตั้ง JDK 21 (LTS) ขึ้นไป และ IDE ที่ถนัด
- มีความตั้งใจฝึกเขียนโค้ดจริงทุกวัน อย่างน้อยวันละ 30-60 นาที

ขอให้สนุกกับการเรียนรู้ และยินดีต้อนรับสู่โลกของ Java!
